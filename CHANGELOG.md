# Changelog

## v1.0.0 - Public Free Release

- Prepared the project for a free GPL-3.0 community release.
- Added clear attribution for QBCore Framework and original qb-banking contributors.
- Preserved the KNBX styled banking UI overhaul.
- Added strict server side money amount validation.
- Added account name and citizen ID sanitization.
- Added account existence guards before balance and type access.
- Added exact shared account user checks instead of substring matching.
- Fixed job and gang boss access conditions.
- Added lightweight per player cooldowns for critical banking actions.
- Added safer PIN validation for bank card creation.
- Added debug logging behind `Config.Debug`.
- Removed nested archive files from the release package.
- Removed oversized preview GIFs from the repository package.
- Removed development comments and editor style leftovers.
- Added README, NOTICE, SECURITY and gitignore files for public release.
