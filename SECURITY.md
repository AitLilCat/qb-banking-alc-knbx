# Security Policy

## Reporting Security Issues

Report security issues through GitHub issues for this repository.

If the issue contains a live exploit path, avoid posting exact abuse steps publicly until the maintainer has reviewed it.

## Scope

Security reports should focus on:

- Money duplication.
- Unauthorized shared account access.
- Unauthorized job or gang account access.
- Server callback abuse.
- Input validation failures.
- Database update issues.

## Server Owner Responsibility

This resource is provided as is under GPL-3.0.

Server owners must test the resource on a development server before production use. Confirm deposits, withdrawals, transfers, invoices, shared accounts, job accounts and gang accounts behave correctly with your server setup.
